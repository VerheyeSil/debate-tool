# Dutch Political Debate Simulator

An LLM-powered tool that simulates political debates between Dutch political parties based on their actual policy positions and party programs. Compare ideologically-consistent AI debates with real Tweede Kamer debates to analyze the signal-to-noise ratio in Dutch politics.

## Overview

This project uses multiple LLM agents to recreate political debates, with each agent trained on specific party manifestos, voting records, and policy documents. A moderator agent orchestrates the debate flow, mimicking the structure of real parliamentary debates.

## Goals

- Create party-specific LLM agents that debate according to their documented positions
- Compare AI-generated "policy-pure" debates with actual Tweede Kamer debates
- Identify where real debates diverge from substantive policy discussion
- Educational tool for understanding Dutch political positions on specific topics
